How to Add / Update Tournaments

It's super easy! Just edit the js/data.js file in your GitHub repo. The site updates automatically within minutes.

📝 Step-by-Step

  • Go to your GitHub repository
  • Open the file js/data.js
  • Click the ✏️ pencil icon to edit
  • Copy one of the existing tournament blocks and paste it
  • Change the details (title, date, map, mode, prizes, etc.)
  • Click "Commit changes" at the bottom
  • Done! Your site updates automatically in 1-2 minutes

📋 Tournament Template (Copy & Paste)

{
  id: 5,  // Change to next number
  title: "Your Tournament Name 🏆",
  game: "BGMI",           // "BGMI" or "PUBG"
  mode: "Squad",          // "Solo", "Duo", or "Squad"
  map: "Erangel",         // "Erangel", "Miramar", "Sanhok", "Vikendi", "Livik"
  date: "2026-11-05T20:00:00+05:30",  // YYYY-MM-DDTHH:MM:SS+05:30 (IST)
  entryFee: "Free",
  prizePool: "₹500",
  maxTeams: 25,
  registeredTeams: 0,     // Update as teams register
  perKillPrize: "₹10",
  roomId: "",             // Add room ID before match (keep empty until ready)
  roomPass: "",           // Add password before match
  status: "upcoming",     // "upcoming", "live", or "completed"
  rules: [
    "Emulator players not allowed",
    "Join room 5 minutes before match time",
    "Captain must share results screenshot"
  ],
  pointsSystem: {
    chickenDinner: 15,
    secondPlace: 12,
    thirdPlace: 10,
    kill: 1
  },
  results: []  // Fill after match ends (see below)
},

⚙️ Site Settings

Edit the SITE_CONFIG section at the top of js/data.js:

  • whatsappGroup: Your WhatsApp group invite link
  • adminContact: Your WhatsApp number with country code (919999999999)
  • name: Change site name from "BattleZone" to yours

🚀 Going Live Checklist

  • Create a free GitHub account (if you don't have one)
  • Create a new repository (e.g., "battlezone")
  • Upload all files (index.html, css/, js/ folders)
  • Go to Settings → Pages → Source: "main" branch → Save
  • Your site is live at: https://yourusername.github.io/battlezone
  • Share the link in your WhatsApp group! 🎉
💡 Pro Tip: Bookmark the GitHub edit link for js/data.js. You can update tournaments right from your phone's browser — no computer needed!
